# 📝 Comment contribuer
- AndroidSamples (Version STABLE)

Nous accueillons volontiers vos correctifs, améliorations et contributions au projet AndroidSamples.  
Pour garantir une collaboration propre et efficace, merci de suivre les règles ci‑dessous.

---

📄 Accord de licence du contributeur (CLA)

Toute contribution à AndroidSamples doit être accompagnée d’un Contributor License Agreement (CLA).  
Vous (ou votre employeur) conservez le droit d’auteur de votre contribution ; le CLA nous autorise simplement à utiliser et redistribuer votre travail dans le cadre du projet.

Consultez ou signez un CLA ici :  
👉 <https://cla.developers.google.com/>

Un CLA n’est généralement requis qu’une seule fois.  
Si vous en avez déjà signé un pour un autre projet, il n’est probablement pas nécessaire de le refaire.

---

🔍 Revue de code

Toutes les contributions — y compris celles des mainteneurs — doivent être examinées avant intégration.

Nous utilisons les pull requests GitHub pour gérer les revues de code.  
Pour plus d’informations sur leur fonctionnement :

👉 Aide GitHub — À propos des pull requests

🌐 Règles de la communauté

Le projet AndroidSamples suit les règles de conduite de la communauté Open Source de Google :

👉 <https://opensource.google.com/conduct/>

---

📌 Notes spécifiques à AndroidSamples (Version STABLE)

- La structure du dépôt est organisée autour de dossiers techniques :  
  projects/, sources/, docs/, .github/  
- Les contributions doivent respecter cette architecture.  
- Toute modification impactant plusieurs modules doit être documentée dans docs/.  
- Les PR doivent être propres, isolées, et accompagnées d’un message clair.  
- Les discussions techniques se font via Issues GitHub.
